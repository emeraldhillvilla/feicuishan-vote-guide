# 粤省事 · 业主投票操作指引

惠州市业主大会电子投票（选聘物业服务企业）的图文操作指引，12 张实机截图按步骤编排，**每张截图都加了红色方框和箭头标出该点哪里**（最后一张除外，见下）。

## 内容

- `index.html` — 完整的响应式图文指引（单文件，无外部依赖）
- 12 张截图 — 从「打开粤省事定位惠州」到「议题列表」的完整链路

## 步骤一览

| 步 | 页面 |
|---|---|
| 01–04 | 找到入口：定位惠州、搜索「业主」、点开「业主投票决议」、确认登录 |
| 05–06 | 选择登录方式、改选人脸识别并勾选同意、点下一步 |
| 07 | 粤省事登录页：核对证件信息、打勾、开始人脸识别验证 |
| 08 | **微信人脸核验页**：确认打勾、点「下一步」 |
| 09 | 授权登录页：点「开始办理」 |
| 10 | 业主投票决议事项页（投票须知） |
| 11 | 页面底部：点「开始投票」 |
| 12 | 议题列表页（**无标注**，见下） |

## 为什么第 12 张没有红框

该页在投票开放前是空白页（「进行中」为 0 项），画出点击位置没有意义，因此保留原图，把说明写在图注里。

## 为什么截图带红框

面向的是小区业主，其中不少是不熟悉手机操作的长者。每张截图都用红色圆角框标出**该点击的位置**，并配一句极短的红底白字提示（如「点这一项」「① 打勾」）。标签刻意做短、字号放大，因为在手机页面上截图只显示约 300px 宽，长句会缩到看不清。

标注框刻意用红色而非页面主色：粤省事自身的按钮是蓝色的，标注若也用蓝，会和界面按钮混淆。

## 本地查看

直接用浏览器打开 `index.html` 即可。截图与页面放在同一目录，需保持相对位置不变。

## 特性

- 响应式：7 组断点，覆盖小屏手机、平板、桌面、横屏矮视口与打印
- 点击截图可全屏放大（支持 Esc 关闭、键盘回车/空格打开）
- 无外部依赖，不加载任何第三方字体、脚本或统计代码
- 尊重系统的「减少动态效果」设置
