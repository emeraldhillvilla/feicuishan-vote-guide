# 粤省事 · 业主投票操作指引

惠州市业主大会电子投票（选聘物业服务企业）的图文操作指引，11 张实机截图按步骤编排，**每张截图都加了红色方框和箭头标出该点哪里**。

## 内容

- `index.html` — 完整的响应式图文指引（单文件，无外部依赖）
- 11 张带标注的截图 — 从「打开粤省事定位惠州」到「议题列表」的完整链路

## 为什么截图带红框

面向的是小区业主，其中不少是不熟悉手机操作的长者。每张截图都用红色圆角框标出**该点击的位置**，并配一句极短的红底白字提示（如「点这一项」「这里打勾」）。标签刻意做短、字号放大，因为在手机页面上截图只显示约 300px 宽，长句会缩到看不清。

## 本地查看

直接用浏览器打开 `index.html` 即可。截图与页面放在同一目录，需保持相对位置不变。

## 特性

- 响应式：7 组断点，覆盖小屏手机、平板、桌面、横屏矮视口与打印
- 点击截图可全屏放大（支持 Esc 关闭、键盘回车/空格打开）
- 无外部依赖，不加载任何第三方字体、脚本或统计代码
- 尊重系统的「减少动态效果」设置
